## Overview

Version 2.2.0 reworks the hero, the stack, the reviews and the footer of [kamycoding.com](https://kamycoding.com) and brings VS Code color themes. The top bar and the intro now read the version from `package.json`, so they follow every release.

## Highlights

- **Color themes**: colors follow VS Code. The dark theme uses Dark Modern, and a Color Theme picker (`T`, the top bar or the status bar) switches between Dark Modern, Light Modern, Monokai and Solarized Dark with live preview. The default follows the system, and every theme meets WCAG AA for text
- **Hero**: only the name and role. The editor can be slid between a live-measured blueprint and the build, and the entrance plays it after the intro. The terminal is rebuilt with a modern prompt, ghost suggestions and real commands such as `ls projects`, `git log` and `blueprint`
- **Stack**: two blocks, the stack as a VS Code style explorer (folders per group, technologies as files, real names on hover and focus) and a full-width GitHub contributions grid for the last 52 weeks with a reveal wave, a pulse on today and a stats line
- **Reviews**: shown as GitHub-style pull request reviews with line-drawn avatars, an approval summary and the quotes as review comments
- **Footer**: a large "kamycoding" line drawing that draws itself once, with the cat lying on its "m". The bottom bar keeps only the copyright and the template credit
- **Version display**: the top bar and the intro show the version from `package.json` instead of a hardcoded `2.0`

## Maintenance

- `@types/node` follows the Node 24 runtime (`24.19.2`, was `22.19.3`)
- Dependabot no longer proposes major updates of `@types/node`; they are raised together with the Node version

## Getting started

Requirements: Node.js 24 (`.nvmrc`) and pnpm (pinned in `package.json`, enabled through corepack).

```bash
git clone https://github.com/kamycoding/portfolio.git
cd portfolio
git checkout v2.2.0
corepack enable pnpm
pnpm install
pnpm dev
```

The app runs at `http://localhost:3000`. The contact function needs the variables in `.env.example` and is tested end to end on Netlify Deploy Previews.
