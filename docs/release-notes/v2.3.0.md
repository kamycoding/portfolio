## Overview

Version 2.3.0 adds the Journal to [kamycoding.com](https://kamycoding.com): a bilingual blog about building software in Germany, written as MDX in the repository, with interactive learning components and audio. It ships with its first article, a journal section on the homepage and a redesigned 404 page.

## Highlights

- **Journal**: `/blog` and `/de/blog`, with static article pages, editor tabs and breadcrumbs, and a `blog/` tab in the top bar and footer. A post that exists in only one language shows a localized notice in the other and links to the published version
- **First article**: "German for Developers: What People Say in Dailies and Calls", in English, with a textbook diff, 20 playable phrases, a word-by-word sentence, a standup dialogue and a quiz
- **Second article**: "The JavaScript Event Loop: Predict the Output", in English and German. Three output puzzles, an event loop stepper, a measured `forEach(async)` timeline and a main thread freeze demo, with claims checked against MDN and the HTML specification
- **Listen to this article**: a narration player with section navigation, three speeds and the playing section marked in the Outline. It is reusable, and only the event loop article has narration for now
- **Reading**: prose at about 70ch, code blocks with filename, copy button, highlighted lines and diffs in all four themes, an Outline with scroll-spy and reading progress in the status bar
- **Learning components**: Term translations in a popover that also opens on hover, Gloss sentences with linked German and English word groups, Dialog with a Show English toggle, Quiz with explanations, and Callout, TLDR, Takeaways and Figure blocks
- **Audio**: play buttons for terms, sentences and dialogue lines. Clips are generated locally with `pnpm audio` and served from the own origin, with a local German voice as fallback. Builds never contact ElevenLabs
- **Homepage**: a `blog/` section between the stack and the contact form is a split editor: an explorer tree with the article's headings, a preview with the TL;DR and a "textbook vs. what people say" diff card with a play button, and a status bar with reading time, terms, audio clips and language
- **Terminal and palette**: `ls blog`, `open <slug>` and `cat blog/<slug>` in the hero terminal, with ghost suggestions, and a Journal group in the command palette
- **Reading cursor**: on journal pages an editor caret over prose, a small ring over links and controls and a dot elsewhere, quieter rulers and no blueprint crosshair, and the cursor stays visible above Term popovers
- **Search and sharing**: posts in the sitemap, an RSS feed per language (`/blog/rss.xml`, `/de/blog/rss.xml`), an Open Graph image and structured data per article, and an author box
- **Logo**: the real kamycoding logo replaces the "k/" mark in the top bar, the author box and the social images
- **404 page**: an editor window with the missing file as a tab, a compiler-style "Module not found" line, a "Did you mean" suggestion for the closest real route and the sleeping cat

## Fixes

- The terminal's `help` command prints the command list again; a `<name>` placeholder in the text had been read as an unclosed tag
- The intro hides its text at once when it ends, so no half-transparent text is left on the page
- The review badge and the key hint on the contact send button reach WCAG AA contrast in every theme

## Maintenance

- The privacy policy describes the journal audio and the local speech fallback, and names all four color themes
- The journal's content model, audio pipeline and homepage data are documented in ADR 0007

## Getting started

Requirements: Node.js 24 (`.nvmrc`) and pnpm (pinned in `package.json`, enabled through corepack).

```bash
git clone https://github.com/kamycoding/portfolio.git
cd portfolio
git checkout v2.3.0
corepack enable pnpm
pnpm install
pnpm dev
```

The app runs at `http://localhost:3000`. The contact function needs the variables in `.env.example` and is tested end to end on Netlify Deploy Previews. Journal audio needs `ELEVENLABS_API_KEY` in `.env.local` only when generating new clips.
